# Quy chuẩn giao diện

## Ngôn ngữ

- Tất cả UI dùng tiếng Việt.
- Không dùng tiếng Anh trong UI, trừ tên thuốc, tên thương hiệu hoặc tên kỹ thuật.

## Phong cách

- Giao diện hiện đại, sạch, đồng bộ, giống app nhà thuốc.
- Cảm giác tổng thể cần tạo sự tin cậy, rõ ràng, dễ đọc và thân thiện với người dùng Việt Nam.
- Khoảng cách thoáng, ưu tiên khả năng đọc và thao tác nhanh trên mobile.

## Màu sắc

- Màu chủ đạo xanh dương.
- Nền chính dùng trắng hoặc xanh rất nhạt.
- Header dùng xanh dương, chữ trắng.
- Trạng thái cảnh báo dùng cam.
- Trạng thái thành công dùng xanh lá.
- Trạng thái lỗi dùng đỏ.

## Thành phần

- Button chính màu xanh dương, chữ trắng, bo góc lớn.
- Card nền trắng, bo góc 16, shadow nhẹ.
- Input bo góc, có icon, focus màu xanh.
- Các danh sách sản phẩm, danh mục và khu vực nội dung cần dùng bố cục thoáng, rõ phân cấp.

## Bảng màu chuẩn

- Primary: `#1976D2`
- Dark blue: `#0D47A1`
- Light blue: `#E3F2FD`
- Background: `#FFFFFF`
- Text chính: `#1F2937`
- Text phụ: `#6B7280`
- Warning: `#F59E0B`
- Success: `#10B981`
- Error: `#EF4444`
