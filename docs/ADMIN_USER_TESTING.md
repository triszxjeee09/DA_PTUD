# Checklist kiểm thử Admin quản lý người dùng

- [ ] Login bằng admin.
- [ ] Vào Quản lý người dùng.
- [ ] Xem danh sách user.
- [ ] Tìm user theo tên/email/số điện thoại.
- [ ] Lọc theo ACTIVE/BLOCKED.
- [ ] Lọc theo CUSTOMER/ADMIN/PHARMACIST.
- [ ] Vào chi tiết user.
- [ ] Khóa tài khoản customer.
- [ ] Mở khóa tài khoản customer.
- [ ] Gán role PHARMACIST.
- [ ] Xóa role PHARMACIST.
- [ ] Test admin tự khóa chính mình.
- [ ] Test tài khoản customer không vào được route admin.
